Reinforcement learning for Slay the Spire

AscensionAI is a from-scratch RL/search system for Ironclad on a headless C++ simulator. Its search now plays honestly — it samples what a player can't see instead of reading the seed — and the current best honest agent wins 5 / 150 fixed seeds (floor 24.4). Every change is A/B-tested on the same 150 seeds.

Project Snapshot

November 2026: an audit found that every earlier search result — including mainline_v3's 9 wins and the draft teacher's 44 — came from search that replayed the true seed, so its rollouts knew the real draw order, enemy rolls and future rewards. Those numbers are now labelled clairvoyant (seed-peeking). The search was rebuilt to sample hidden information instead of reading it (exact C++ state copies + determinization), which dropped the agent to 1 win / floor 22.4 — the honest baseline. A native batched C++ rollout engine (bit-identical to the Python search, ~11× faster per run) then made far more samples affordable: K=32 sampled worlds per decision reaches 5 wins / floor 24.4, the current best honest result.

Roadmap

Honest search is now the project's standard: any search may sample hidden information, never read it. Each phase ends in a 150-seed gate against the previous honest baseline.

done

Phase 0 — Reproduce

Rebuilt the sim on a WSL2 laptop (no sudo); mainline_v3 reproduced byte-for-byte on all 150 seeds.

done

Phase 1 — Honest search

C++ copy()/determinize(); honest 1-ply combat and draft teacher. Baseline: 1 win, floor 22.4 (014).

in progress

Phase 2 — Native C++ search

Batched AVX2 rollouts (bit-identical, ~37×/rollout), ensemble MCTS, adaptive samples, potion conservation. Best so far K=32: 5 wins, floor 24.4.

next

Phase 3 — Consistent Ironclad A0 wins

Expert iteration with search at play time: honest K-sample search for every non-combat decision, prior + value nets trained on honest search outputs, one run-level value. Milestones 25% → 50% → 75% → 85%+.

later

Phase 4 — Ironclad ascensions

Ascension in the observation, curriculum by band (A1–5 … A16–20). Targets A10 70%+, A15 55%+, A20 40%+.

later

Phases 5–6 — Silent, Defect, Watcher

Implement the missing class logic in the sim, differential-tested against the real game; character-agnostic observation; rerun Phases 3–4 warm-started from Ironclad.

later

Phase 7 — Completion

Act 4 and the Heart; real-game validation per character × ascension; final win-rate table with CIs on held-out seeds.

Full plan: Path to max win rate on all characters and ascensions.

System In Motion

AscensionAI trains as a distributed worker/trainer loop: rollout workers write checkpoint-tagged data, an offline trainer consumes fresh batches, saves an updated checkpoint, and workers reload the policy for the next cycle. The animation shows the live-game version; the headless simulator uses the same process-separated pattern at ~190× the throughput.

Current Results

The current best honest agent is mainline_v3's macro stack with honest combat search at K=32 sampled worlds per decision: 5 wins / 150, floor 24.4. The earlier mainline results are kept below as clairvoyant (seed-peeking) references; their macro levers (deck hygiene, role scorer, tempo smithing) carry over unchanged.

Honest K=32 (current best) honest

150 fixed seeds: 24.4 avg floor, 5 wins, vs the honest K=8 baseline 22.4 / 1 (paired floor gain +2.0, 95% CI +0.8–+3.1). Native batched C++ rollouts make 32 samples per decision cheap.

AscensionAI is a public portfolio project by Justin Chan. Experiments run on a headless Slay the Spire C++ simulator (sts_lightspeed) under WSL2 on a local workstation (the GCP VM was retired in July 2026), with a live install kept as a transfer-eval oracle; the sim code is in sim/.
